# 3-Month Portfolio Roadmap (SDET-level)

This roadmap is practical for EU hiring expectations and focuses on
reliability, architecture, and CI readiness.

## Month 1 - Foundation and E2E framework
Goals:
- Strong profile README and portfolio structure
- First flagship project: Playwright E2E framework

Week 1
- Finalize README and docs structure
- Create project skeleton and CI workflow
- Add baseline test report output

Week 2
- Implement POM, fixtures, and selector strategy
- Add 3-5 stable tests with strong assertions
- Add diagram of architecture and data flow

Week 3
- Add parallel execution support and data cleanup
- Document retries policy and flaky-test mitigation
- Add examples showing Arrange/Act/Assert

Week 4
- Polish docs and run instructions
- Add short demo video or screenshots
- Publish and pin repo

## Month 2 - API testing and quality gates
Goals:
- API testing toolkit with schema and contract checks
- CI quality gates and reporting

Week 5
- Create API test framework project skeleton
- Add schema validation and environment config

Week 6
- Add contract tests or OpenAPI validation
- Add data builders and reusable helpers

Week 7
- Integrate CI workflow with reports and artifacts
- Add failure triage checklist in README

Week 8
- Polish docs and add example tests
- Pin the project and update profile summary

## Month 3 - Architecture demo and non-functional checks
Goals:
- Test architecture demo and performance/security smoke checks

Week 9
- Build test pyramid demo with data strategy
- Add risk-based test coverage map

Week 10
- Add k6 performance smoke tests and thresholds
- Add OWASP ZAP baseline scan in CI

Week 11
- Improve reliability and error handling in CI
- Add runbooks for common failures

Week 12
- Final polish, clean commit history, update pinned repos
- Create a short portfolio summary in profile README

## End-of-roadmap outcomes
- 3-5 high-quality repos with CI badges
- Clear architecture documentation and diagrams
- Evidence of reliability and ownership
- A recruiter-friendly profile that shows leadership potential
