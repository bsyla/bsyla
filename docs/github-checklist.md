# Senior QA GitHub Checklist

Use this checklist to make your GitHub profile look SDET-level and
recruiter-friendly.

## Profile optimization
- Clear headline: "SDET / QA Automation Engineer"
- Short summary focused on impact and reliability
- Pin 4-6 repos that show architecture and CI
- Add location and time zone for EU roles
- Keep contact info easy to find

## Commit hygiene
- Small, logical commits with descriptive messages
- Avoid "WIP" or "fix" messages in main branches
- Use branches for experiments and keep main clean
- Show progression: README updates, tests, CI, docs

## Documentation standards
- Every repo has a clean README with setup and run steps
- Explain why decisions were made, not just what they are
- Include limitations and next steps
- Keep instructions copy-paste friendly

## Architecture diagrams
- Add a simple diagram per project (even a small box diagram)
- Explain test layers, data flow, and CI triggers
- Store diagrams under diagrams/ with a short README

## Badges and metrics
- Add CI status badge for key repos
- Include coverage or report badges only if accurate
- Avoid noisy badges (too many reduces clarity)

## Common mistakes to avoid
- Hardcoded waits and flaky selectors
- Huge single repo with mixed experiments
- Projects that do not run without manual steps
- Overstated claims without proof
- Readmes that skip setup, data, or CI details
